Privacy and permissions

No account is needed. Progress, notes and history are stored only in this browser on this device.

Location. Asked for only when you tap "Use my location". It places you on the radar and checks arrival. It is never uploaded. Discoveries keep only a rounded position, accurate to about 100 m.

Microphone and camera. Not used.

Creators. If you stream, do not show your live position on screen. Overlays will never show coordinates unless you switch that on yourself.

Check-ins. A check-in earns the full reward only with a real location fix close to the destination. Without one, you can do a labelled demo check-in for a reduced reward.

What is simulated in this build

  • The radar is a plain radar view, not a street map. Street maps and routes need a map service this preview cannot reach.
  • Generated destinations are random coordinates. Nothing checks roads, water or access.
  • The EMF meter and spirit box are random entertainment effects.
  • Offline: once loaded, the game keeps working without a connection. Installing it as an app is planned for the standalone version.

Display

Phone preview shows the game in a phone-sized frame, so you can see the portrait layout on a larger screen.

Install on your iPad or phone

When GhostQuest is opened from its own web address, tap Share, then Add to Home Screen. It then opens full screen like an app and keeps working without a connection. A file opened straight from Files does not do this.

Your artwork

Swap in a new image from this device. It is stored in this browser only. Use a world image with the same layout (stone left, gateway right) so the entrances line up.

Coming later
